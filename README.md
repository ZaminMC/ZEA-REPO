# ZEA-REPO

Community-maintained EarthMC data consumed by
[ZEA](https://github.com/ZaminMC/ZEA), Zamin's EarthMC Addon.

ZEA-REPO stores only **curated, stable, community-verified data**: badge
meanings, chat channel definitions, and curated nation/town descriptions.
Live data (residents, balances, coordinates, online status) is always
fetched from the official [EarthMC API](https://earthmc.net/docs/api) by
the mod at runtime — this repository never duplicates it.

## Structure

```
ZEA-REPO/
├── manifest.json                 CI-generated file index (never edit by hand)
├── schemas/                      JSON Schema for every data shape
├── datasets/
│   ├── badges.json               chat badge symbols and verified meanings
│   ├── channels.json             server channels, observed chat tags, feeds
│   ├── nations/<slug>.json       curated nation entries
│   └── towns/<slug>.json         curated town entries
├── scripts/validate.py           validation + manifest generator
└── docs/DESIGN.md                why the repository is shaped this way
```

## How ZEA consumes it

1. Fetch `manifest.json` (raw GitHub URL, HTTP-cached).
2. Compare per-file sha256 hashes against the local cache.
3. Download only changed files; delete removed ones.

The initial sync can alternatively use the branch zip archive. There is no
API server or database backend — this is a static, Git-hosted repository.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md). Every pull request is validated by
GitHub Actions (`scripts/validate.py`); the manifest is regenerated by CI on
merge, so contributors never touch it.
